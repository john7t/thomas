還沒設定 LIFF ID

  1. 到 LINE Developers 的 LINE Login channel → LIFF → Add。
  2. Endpoint URL 填這一頁的網址：
  3. Size 選 Full；Scopes 勾 openid、profile、chat_message.write。
  4. 建好後把 LIFF ID 貼在下面，或改這個檔案最上面的 LIFF_ID（建議，手機上才不用每次貼）。
